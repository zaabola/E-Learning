Put extra reading here to make the coach's retrieval richer.

Any .txt or .md file in this folder is split into ~120-word passages and searched together with the
tip cards. The first line of the file is used as its citation, for example:

  Stand up, Speak out (2016), ch. 14 Delivery. CC BY-NC-SA 4.0. https://open.lib.umn.edu/publicspeaking/

Good material: the anxiety and delivery chapters of the open textbooks listed in ../sources.md
(copy the chapter text from the website). Passages found here are given to the LLM as extra context
and shown in the tip's "retrieved" list; they never replace the card's own source line.
This README itself is ignored.
